# 🏨 HotelUI — Tam Kapsamlı Katmanlı Mimari Otel Otomasyonu

ASP.NET Core 9.0 ve Entity Framework Core 9 teknolojileriyle geliştirilen; Web API, MVC UI, Identity ve SQL Server altyapısına sahip kurumsal otel yönetim sistemi.

## 🚀 Mimari & Katmanlar
- **Data Access Layer (DAL):** EF Core 9 Code-First, Migration yönetimi, Repository pattern.
- **Business Layer (BLL):** Servis katmanı, iş kuralları ve DTO dönüşümleri.
- **Web API & MVC UI:** RESTful uç noktalar, ViewModel'ler, dinamik rezervasyon paneli.
- **Güvenlik:** ASP.NET Core Identity ile rol bazlı yetkilendirme.
