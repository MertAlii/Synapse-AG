# 🛡️ ThreatIntel AI — Otonom Oltalama (Phishing) Analiz Asistanı

Şüpheli e-postaları ve siber güvenlik tehditlerini yerel LLM (DeepSeek R1 / Ollama) ile analiz eden otonom asistan.

## 🚀 Öne Çıkan Özellikler
- **178 MITRE ATT&CK Tekniği:** Vektörel bilgi tabanı olarak ChromaDB üzerinde indekslenmiş MITRE kütüphanesi ile zenginleştirilmiş [[RAG-Architectures]].
- **Deterministik Entegrasyonlar:** VirusTotal API sorgulaması, RDAP/WHOIS domain yaş ve DNS kontrolleri.
- **Risk Skorlama Motoru:** Halüsinasyon içermeyen deterministik risk katsayısı hesaplama (Flask backend).
