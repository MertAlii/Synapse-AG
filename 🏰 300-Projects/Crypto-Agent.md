# 🚀 Crypto-Agent — Otonom Kripto Analiz & İşlem Simülatörü

Qwen 2.5 7B modeli ile Tool Calling (fonksiyon çağırma) mimarisi kurularak geliştirilen sanal portföy ve finansal analiz ajanı.

## 🚀 Öne Çıkan Özellikler
- **Canlı Piyasa Verisi:** Binance.US API entegrasyonuyla anlık fiyat ve volatilite takibi.
- **Sanal Portföy Motoru:** SQLite3 veri tabanı ile bakiye, alım-satım emirleri ve kâr/zarar takibi.
- **Deterministik Hesaplama:** Model emir verir, backend kodu matematiksel doğrulukla emri icra eder.
- **Arayüz:** Gradio ile reaktif kullanıcı etkileşimi.
